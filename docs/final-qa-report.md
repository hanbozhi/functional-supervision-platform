## 5. 本轮发现并修复的问题

共修复 7 类确认问题：

1. 3 个历史业务测试和 1 个数据库基础设施测试仍把迁移总数写死为 V004/V005/V006，导致 V013 基线下误报失败；改为检查目标迁移只执行一次或统一使用 13 版预期。
2. Windows 上并发迁移测试可能同时创建尚不存在的 SQLite 文件并触发 `SQLITE_CANTOPEN`；测试先安全创建数据库文件，并等待线程池有序结束。
3. m2-1～m2-14 使用的 5 个 API 模块绕过 `VITE_API_BASE`、固定请求 `/api`，导致临时/非同源环境误连其他后端；现已统一复用公共 `API_BASE`。
4. m2-11 未选择文件时“创建归集批次”静默无反应；现显示明确错误。
5. m2-9 后端表单校验失败仍使用成功色提示；现区分成功与错误，并补充服务事项保存成功反馈。
6. m2-8 加载、保存、提交、复核和材料上传失败使用成功色提示；现统一区分成功与错误。
7. m2-14 加载、选择、规则检查、处置和模拟提醒缺少完整异常反馈，清空选择还可能请求空 ID；现增加异常提示和空选择保护。
