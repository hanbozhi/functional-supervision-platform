# 未完成功能清单

本文档记录当前阶段暂缓的外部系统和智能能力。开发阶段应优先完成本地可验证的业务流程，并在接入真实能力后更新状态。

真实登录、密码验证、身份认证和权限控制不属于“待完成”功能，当前项目明确不实现；用户和角色数据仅服务于业务操作人及角色展示模拟。

## 维护规则

- 每轮开发完成后同步更新本文件。
- 本地模拟必须保留来源、执行批次、状态和错误信息，便于以后替换为真实适配器。
- 模拟逻辑不得伪装成真实外部调用；页面和接口返回应明确标记数据来源。
- 接入真实外部服务前不得在仓库中保存密码、密钥、Token或个人敏感数据。
