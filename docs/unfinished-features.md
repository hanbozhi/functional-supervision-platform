## 维护规则

- 每轮开发完成后同步更新本文件。
- 本地模拟必须保留来源、执行批次、状态和错误信息，便于以后替换为真实适配器。
- 模拟逻辑不得伪装成真实外部调用；页面和接口返回应明确标记数据来源。
- 接入真实外部服务前不得在仓库中保存密码、密钥、Token或个人敏感数据。
